# Hướng Dẫn Chuẩn: Tích Hợp Supabase Vào Form RSVP (Buổi 5)

Tài liệu này dành cho học viên và người phát triển dự án thiệp cưới online, giúp kết nối form RSVP với Supabase Database một cách nhanh chóng, chuẩn xác, tránh gặp lỗi và tiết kiệm tối đa token khi làm việc cùng trợ lý AI.

---

## ⚠️ 3 Bẫy thường gặp cần tránh

1. **Bẫy ghi đè `app/page.tsx`**: Trang bắt đầu của Supabase gợi ý code mẫu lấy danh sách `todos` đặt trong `page.tsx`. **Tuyệt đối không ghi đè `app/page.tsx`**, vì file này đang chứa toàn bộ giao diện thiệp cưới.
2. **Bẫy lệch tên bảng và tên cột (`PGRST205` / `PGRST204`)**: Tự tạo bảng bằng tay dễ dẫn đến đặt tên không đồng nhất (`rsvps` vs `rsvp_guests`, `name` vs `guest_name`...).
3. **Bẫy bảo mật Row Level Security (`42501`)**: Supabase mặc định bật RLS nhưng không cấp quyền ghi cho khách truy cập, dẫn tới lỗi `new row violates row-level security policy`.

---

## 🛠️ Quy Trình 4 Bước Chuẩn

### Bước 1: Tạo bảng & Mở quyền trong Supabase (Chạy 1 đoạn SQL duy nhất)

1. Đăng nhập vào [Supabase Dashboard](https://supabase.com/dashboard) và chọn dự án của bạn.
2. Vào mục **SQL Editor** ở thanh menu bên trái.
3. Bấm **New query**, dán toàn bộ đoạn code dưới đây và bấm **Run**:

```sql
-- 1. Tạo bảng rsvp_guests chuẩn
create table if not exists public.rsvp_guests (
  id bigint generated by default as identity primary key,
  guest_name text not null,
  phone text not null,
  status text not null default 'yes',
  guest_count integer default 1,
  wishes text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Kích hoạt bảo vệ dữ liệu Row Level Security
alter table public.rsvp_guests enable row level security;

-- 3. Cho phép khách mời gửi xác nhận (Insert công khai)
create policy "Cho phép khách mời gửi RSVP"
on public.rsvp_guests for insert
with check (true);

-- 4. Cho phép đọc danh sách xác nhận (Select công khai)
create policy "Cho phép đọc danh sách RSVP"
on public.rsvp_guests for select
using (true);
```

---

### Bước 2: Cấu hình biến môi trường (`.env` hoặc `.env.local`)

1. Trên Supabase, vào **Project Settings** (biểu tượng bánh răng) ➔ **Data API** (hoặc **API Keys**).
2. Sao chép **Project URL** và **Publishable Key** (hoặc `anon` key).
3. Mở tệp `.env` (hoặc `.env.local`) ở thư mục gốc dự án và điền vào:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<your-project-id>.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

*(Lưu ý: Tệp `.env` và `.env.local` đã nằm trong `.gitignore`, không sợ bị lộ khi đẩy lên GitHub).*

---

### Bước 3: Cài đặt thư viện cần thiết

Mở Terminal tại thư mục dự án và chạy lệnh sau:

```bash
npm install @supabase/supabase-js @supabase/ssr
```

### Bước 4: Mẫu Prompt chuẩn gửi cho AI Coding Assistant

Copy toàn bộ đoạn bên dưới gửi cho AI (Antigravity, Cursor, Claude Code, v.v.):

```text
Dự án của tôi là Landing Page thiệp cưới online (Next.js App Router).
Tôi đã tạo bảng `rsvp_guests` trên Supabase với các cột:
- `guest_name` (text, họ và tên khách mời)
- `phone` (text, số điện thoại)
- `status` (text, 'yes' hoặc 'no')
- `guest_count` (integer, số lượng người đi cùng)
- `wishes` (text, lời chúc)

URL và Publishable Key đã được lưu trong file `.env`.

Yêu cầu:
1. Tạo tiện ích client trong `utils/supabase/client.ts` sử dụng createBrowserClient.
2. Kết nối form RSVP trong `components/wedding/RsvpSection.tsx` để lưu thẳng dữ liệu vào bảng `rsvp_guests` của Supabase, thay thế hoàn toàn việc lưu bằng LocalStorage.
3. TUYỆT ĐỐI GIỮ NGUYÊN 100% giao diện, phong cách và các section hiện có trong `app/page.tsx`, không được ghi đè trang chủ.
4. Xử lý trạng thái gửi (loading) và hiển thị thông báo lỗi nhẹ nhàng nếu mất mạng.
```
